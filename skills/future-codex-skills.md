# Future Codex Skills

STREM can eventually define Codex skills to standardize repeated work.

## Candidate Skills

### strem-service-planner

Purpose:

- create service design docs
- validate ownership
- check repository strategy
- identify contracts and events

Inputs:

- feature brief
- target service
- affected data

Output:

- implementation plan
- risks
- test plan

### strem-contract-reviewer

Purpose:

- review OpenAPI and event schema changes
- check compatibility
- identify consumers

Output:

- contract review findings
- migration notes

### strem-ai-safety-reviewer

Purpose:

- review AI transformation coach behavior
- check unsafe advice
- check prompt injection risk
- verify escalation behavior

### strem-mobile-flow-reviewer

Purpose:

- review mobile UX flows
- check accessibility
- check loading/error/empty states
- verify MVP scope

### strem-release-checker

Purpose:

- run release checklist
- inspect test status
- verify docs
- identify rollback risk

## Skill Rules

Future skills must:

- read `AGENTS.md`
- stay scoped
- avoid implementation unless their purpose requires it
- output structured findings
- respect MVP boundaries
